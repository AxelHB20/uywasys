-------------------------------
Ultimas lineas del sistema:

Buscar un codigo de error que te mando la clinica (ej. 7F3A09C2):
uywa logs api | grep 7F3A09C2

Problemas con el envio de correos:

4. RESPALDOS (en el servidor)
-----------------------------
Se hacen solos todas las noches a las 3:15 a.m. al Drive de la clinica.

Ver si corrio anoche:
uywa logs backup --tail 20

Hacer un respaldo ahora (SIEMPRE antes de actualizar):
uywa exec backup backup.sh

Ver la lista de respaldos guardados:
uywa run --rm backup restore.sh lista

Prueba de restauracion (no toca la base real; hacerla 1 vez al ano):

RESTAURAR (solo ante un desastre, borra lo actual y pone el respaldo):

uywa run --rm backup restore.sh latest SI-RESTAURAR
uywa start api

------------------------------------------------
Hace falta si alguien cambia la contrasena del Gmail de la clinica (los correos dejan de salir).

a) En https://myaccount.google.com/apppasswords (cuenta gomezmedic.sac):
   borra las anteriores, crea una nueva llamada Uywa y copia las 16 letras.

b) En el servidor, un comando a la vez:
sed -i '/^SMTP_PASS=/d' ~/uywa/.env
read -s -p Clave: P; echo; printf 'SMTP_PASS=%s\n' "${P// /}" >> ~/uywa/.env; unset P
